Optional: auto-load from your Google Sheet

One-time upgrade so you never paste again: in Google Sheets open File → Share → Publish to web, choose a tab, pick Comma-separated values (.csv), publish, and paste each tab's link below. The dashboard will pull fresh data every time it opens. Heads up: anyone who has a published link can read that tab — full names included — so share it deliberately.
